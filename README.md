# ToDo Reminder
A small Windows Forms app in C# for managing tasks with priorities.

## Features
- Add, edit, and delete tasks  
- Mark tasks as completed  
- Set priority (Low, Medium, High)  
- Save and load tasks from a local file  

## How to Run
1. Clone or download this repository  
2. Open `ToDo Reminder.sln` in Visual Studio  
3. Press **F5** to build and run  

## Usage
Enter a task, set its priority, and save it.  
You can mark tasks as done, edit them, or remove them.  
Tasks are saved and reloaded when you restart the app.
